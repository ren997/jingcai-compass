## 伤停因子：否决（数据口径不成立）

起因是查 `football-info` 的伤停能不能进回测。结论：`injuries[]` **不是当场快照**。

- `players[]` 才是逐场快照：首尔 FC 14 名球员跨 4 场出场数逐个 +1，14/14 单调不减。
- `injuries[]` 与它自相矛盾：穆西亚拉在 06-21 / 06-26 / 06-30 三场德国队比赛里都被标
  `isInjured=true`，而**同一份响应**的 `players[]` 显示他场场首发（starts 1→2→3）。
- 旁证：被标伤停的球员已出现 3/3、4/4 的满覆盖，真实伤停不会覆盖整个 4 个月。

判定后立即停掉归档（跑到 150 场），省下约 1000 次调用。随机 60 场抽样零失败，
覆盖率：`injuries` 非空 77%、`players` 两队全空 30%。

顺带确认两个口径：`feature`/`result` 是滚动 20 场、按场次重新生成
（首尔 FC `homeTeamTotalGoals` 34→31→31→32），`resultDetails` 最大日期止于开赛前；
`history` 块是**两队 H2H** 而非近 20 场（`totalMatches` 常为 2~3），容易拿错。

## 只靠盘口调参的极限（参数敏感性扫描）

用户问「只靠盘口预测调整参数能行吗」。在 7/8/9 月 baseline 806 条已结算腿上做扫描
（参数只决定发不发、不改判什么，已实测方向 100% 一致，所以可在现有腿上直接重算，
无需重跑回测）。腿级导出 `DumpLegs.java` → `legs.csv`（含每行 margin/signal 重算），
分析 `param_sweep.py`。

结论：**不行，而且两个旋钮目前根本没在过滤**。

| 检验 | 结果 |
|---|---|
| 基准 806 腿 | ROI −0.55%，t=−0.18（7/8/9 = +4.24 / −0.89 / −3.50） |
| margin 上限 0.10 | 实测 margin ∈ [0.0174, 0.0560] → **上限从未触发** |
| signal 下限 0.025 | 实测 signal ∈ [0.0256, 0.1208] → **一条没剔除** |
| HIGH 档（signal≥0.075） | 52 腿 ROI **−16.51%**；剔掉它整体从 −0.55% → **+0.55%** |
| margin 回归 | 斜率 +1.16，t=+0.26；分月 +0.29/−2.01/+4.31（符号乱跳） |
| signal 回归 | 斜率 **−3.40**，t=**−1.86**（越大越亏，与现有标签方向相反） |
| 低抽水 vs 高抽水 | −1.92% vs −2.22%，差 +0.30pp，bootstrap p=0.97 |
| 1927 组合网格 | 最优仅 +0.66%（n=467），噪声 ±7.8% → 没有任何角落能到 +3% |
| 样本外（7+8→9 月） | −0.16% vs 基准 −3.50%，改善 3.34pp（±15.7） |
| 反向（9→8 月） | −1.99% vs 基准 −0.89%，**变差** 1.10pp |

**两个方向样本外结论相反 → 那 3.34pp 是噪声，不是效应。**

数学原因：p_model ≡ p_market（edge 恒为 0）⇒ 单腿期望 E = 1/T − 1 = −margin/(1+margin)，
只由水位决定。参数只是「从负数里挑绝对值小的」，改不了符号。

**不要反着调**：signal 斜率 t=−1.86 只有边缘显著（7 月 t=−0.47、9 月 t=+0.24），
反过来把 HIGH 条件改成「signal 小」同样是在拟合噪声。

## 四个方向全部证否（只靠盘口的极限）

用户问「不能调整策略吗」。逐一验过，四条路都堵死：

| 方向 | 做法 | 结果 |
|---|---|---|
| 调参 | margin/signal 阈值 | 旋钮空转（上限/下限都没生效），网格最优 +0.66% 在 ±7.8% 噪声内 |
| 换边 | 反向押高赔率侧 | −0.87% → **−4.23%**，命中 47.0% vs 平衡点 49.0% |
| 比价 | 冻结行改取押注侧最高价 | 全部样本 +1.99%/腿（看似转正），**≤1h 严格同窗口只剩 +0.57%** → 仅 +0.3pp |
| 独立 λ | `feature`/`result` 20 场滚动战绩 | β=+0.0432 **t=+0.78**，最优权重 4.3% |

### 关键事实

- **模型 882/884 = 99.8% 押低赔率侧**。这不是策略而是恒等式的必然：`p_model ≡ p_market`
  ⇒「概率更高」≡「赔率更低」。用户观察对，但这就是「模型在复述市场」的直接证据。
- **押低赔率侧后，盈亏平衡命中率是 54.0% 不是 50%**（平均赔率 1.851）。实际 53.0%，差 1pp。
  这是「命中率过半却不赚」的全部原因。
- **跨庄比价的第一版是假象**：平均价差 +1.99% 让 ROI 变成 +0.07%，但 24.5% 的腿「最高价」
  来自滞后 >6h 的僵尸报价（p90 43h、max 98h）。按 ≤1h 窗口收紧后价差单调塌到 0.57%。
  最高价来源是平博 54%/利记 28%/1xBet 11.5%，**不是交易所**（必发只 1.7%），
  且赢的腿价差 +1.97% vs 输的 +2.12%，**无前视泄漏**——所以 0.57% 是真的，只是不够。
- **独立 λ 不只不显著，是「即使显著也太小」**：775 场 / 1550 观测，
  MAE 纯市场 0.9137 → 样本内最优混合(w=.043) 0.9135（改善 0.02%）→ **β 95% 上界(w=.151) 0.9148 比纯市场更差**。
  即最优混合权重只有 4.3%，市场已含 95.7% 的可预测信息。

**归档**：football-info 全量完成，1038 场新采 / 150 复用 / 0 失败（`fi-archive` 1188 文件）。
赔率 payload 导出 598 场到 `odds-payload`（41MB）。

### 剩下唯一没验的

**入场时点（价格动量）**：同场从开盘到停更赔率能走 3~5%，比跨庄 0.57% 大一个量级。
若漂移可预测，等更好的价即可吃下——这是「买得便宜」而非「赢过市场」。

### 第一版口径错误（已修正，记下来免得再犯）

用「市场中位价」当基准 → CLV = −1.68%（t=−13.9）、冻结价比中位价高 +1.84%（t=+34）。
看着像"系统性买贵 1.8%"，其实是**冻结行的选择方式决定的**：按 `margin` 最小选，
而 margin 小 = 两边赔率都高，所以冻结价天然高于中位价。**这是水位差，不是择时。**

同庄同边口径（平博）：CLV = **+0.358%（t=+1.76）**，51.4% 的腿收盘价更好。
分月 +2.06 / −0.52 / +0.83 / +0.36 / −1.32，**符号乱跳**。

### CLV 能做什么、不能做什么

- 后验诊断：CLV 略正 → 发布时点不差（等到冻结才买，比开盘多拿 0.78%）。**可做监控指标。**
- 前验筛选：**不行**。低 CLV 组 ROI +4.18%、高 CLV 组 −4.49%，斜率 t=−1.82（方向反）。
- 但 CLV 只有 +0.36%，远小于 3.02% 水位 → **证明不了 edge，只证明拿到的是公允价**。

### 入场时点

| 区间 | 价差 | t | 能否吃到 |
|---|---|---|---|
| 开盘→冻结 | **+0.78%** | +4.10（5 月符号一致） | 已吃到 |

## 「还能怎么优化模型」——又验四条，全否

用户问还能怎么优化。补验四个未试方向，全部证否，累计九条。

| 方向 | 数据 | 结论 |
|---|---|---|
| 跨线挑线（同庄不同 line 定价不自洽） | 让球违反单调 10.4%、大小球 3.5% | **最大错价 1.87pp < 水位 2.80pp**，不构成套利 |
| 赔率选样（favorite-longshot bias） | 884 腿赔率区间 1.71~2.03，p5=1.79/p95=1.89 | **无光谱**：<1.7 与 >2.1 各 0 条 |
| 只做低水位市场（砍大小球） | 让球 +0.38% / 大小球 −2.16% | 分月乱跳：10 月让球 **−31.6%（t=−2.09）**、大小球 +15.6% |
| 赛前线稳定性过滤 | 24h 内最平衡线是否移动 | 没动 −1.75% vs 动过 −1.19%；分月 −38.8% / +37.3% |

### 结构性天花板（这轮最重要的发现）

**亚盘两侧赔率被 ±0.25 阶梯锁死在 1.8~1.9**（884 腿全部落在 1.71~2.03）。
→ 平衡命中率恒为 ~54%，市场隐含也是 54%，**没有容错空间**。
→ favorite-longshot 这类「靠赔率光谱选样」的办法彻底没空间（光谱只有 ±5%）。

**上游也没有宽光谱市场**：`/nova/tf/odds` 只给「亚盘让球」「大小球」两种玩法、
7 家机构（10Bet/平博/利记/Bet365/1xBet/韦德/必发，必发仅 24/80 场），无独赢/让球胜平负。
而竞彩胜平负（1.2~10）水位约 27%。**水位与光谱反向，没有交集。**

### 仅存三条路

1. **降水位**（唯一能动符号）：3.02% → 2.0% 打平、1.5% → +0.65%。渠道问题不是模型问题。
2. **换定位**：下注依据 → 市场共识解释器 + CLV 监控（同庄口径 +0.36% 是健康值）。
   顺带：40% 样本利用率不是缺陷，每天拒掉六成场次本身就是能力。
3. **换数据源**：宽光谱 + 低水位同时满足，基本只剩交易所独赢盘。

**不要做**：继续调参/加因子（期望 <0.5pp、噪声 ±6pp，永远验证不了）；
加伤停/xG（λ 仍走「反解→投影」，`edge ≡ 0` 不会被新特征打破，**要改必须改估计量**）。

脚本：`crossline.py` / `calibration.py` / `linestability.py`；`legs.csv` 已加 `league` 列（34 联赛，最大 78 腿，分层必过拟合）。

## 用 O/U 6.5 盘口检验「7+」——第十条否证，但这次是对标的物的直接定价

脚本 `over7.py`。**关键发现：`/tf/odds` 的大小球有 6.5/7.5/8.5 线，6.5 覆盖 593/598 场**——
这就是「7 球及以上」的直接盘口，不用反解 λ。

| 检验 | 结果 |
|---|---|
| 市场隐含 p(>=7)（各家去水后中位） | **4.59%** |
| 实际出现率 | **3.88%** → 市场**高估 18%** |
| 水位 | over 中位 21 倍、under 中位 1.010 → 中位水位 **3.36%** |
| 跨庄取最高价买 over | 平均 23.7 倍，**ROI −7.96%**（打平需 25.8 倍） |
| 跨庄取最高价买 under | 平均 1.0189，**ROI −2.06%**（打平需 1.0403） |
| 时效窗口（over） | 全部 −8.0 / ≤24h +8.5 / ≤6h −8.9 / ≤1h −100（0 命中） → **全噪声** |

**筛选本身有效，但市场定价更狠**：按 6.5 最高价四分位（等价于按预期进球分组）

| 分位 | 平均最高价 | 实际 7+ | 市场隐含 | 实际/隐含 |
|---|---|---|---|---|
| Q1（高进球） | 12.9 | **5.41%** | 7.77% | 0.70 |
| Q2 | 18.7 | 6.76% | 5.34% | 1.27 |
| Q3 | 24.3 | 2.03% | 4.12% | 0.49 |
| Q4（低进球） | 39.0 | 1.34% | 2.57% | 0.52 |

**Q1→Q4 实际率差 4 倍（5.41%→1.34%），但市场隐含也差 3 倍，且每个分位都高估。**
按隐含概率四分位比值 0.51 / 0.83 / 1.15 / 0.59 不单调 → 已定信息，无超额。

**核心结论：longshot bias。over 6.5 的水是 −8%，不是主盘的 −2.9%（2.5 倍）。**
高赔选项被「买冷门的人多」压价，所以「出得多」是真的，但赔率被压得更低。
唯一便宜的是 under 6.5（−2.06%，比主盘还低），但赔率仅 1.018，年化收益无意义。

**不要做**：任何形式的 7+ / 比分玩法。上游 6.5 线本身已是最优筛子，它说 4.59%、实际 3.88%。

## 第十一条否证 + 一条旧结论的修正（10-28 晚，用户问「足球到底能不能赚钱」）

**修正「edge ≡ 0」的理解**：λ 从主盘去水概率反解，只保证「同一条主盘线上 模型概率 = 去水概率」。
但决策链后面还有「邻线聚合 → 中位 → 归一 → 按方向取 1−p」，走完就不再相等。
实测 884 腿比恒等式理论值好 **+2.05pp**（理论 −2.93% vs 实测 −0.87%）。
→ **「模型没信息」是错的说法**，准确说法是「模型方向系统性偏向低赔侧，且这个偏向为负」。

**命中率口径比 ROI 灵敏得多（关键方法）**：
- 884 腿实际命中率 **49.94%**（HIT 1 / HALF_WIN .5 / PUSH .5 / HALF_LOSS 0 / MISS 0）
- 该平均赔率 1.851 的平衡点 **54.02%** → 差 **−4.08pp，t = −2.43**
- 而 ROI 的 t 只有 −0.30。**「亏损在统计上可确认」这个结论只能靠命中率得出，ROI 得不出。**
- 以后判「有没有方向能力」用命中率，判「值多少钱」用 ROI，别混。

**押注侧赔率分层（看起来是信号，分月散了 → 记为噪声）**：
- 882/884 = 99.8% 的腿押的是低赔侧 → 「永远押低赔」≈ 原样（−0.88%），「永远押高赔」= **−4.22%**（与旧记录一致）
- 单调分层：1.71~1.83 −6.22% / 1.83~1.85 −2.61% / 1.85~1.88 +0.07% / 1.88~2.03 +5.27%，Spearman rho=+0.239 **t=7.32**
- **分月立刻散**：5 个月里 3 个成立、2 个反向（9 月 +0.03 vs −5.37；10 月 −17.42 vs −10.74，n 只 12）。+9.58pp 差值几乎全由 8 月单月贡献。
- 阈值扫描 po>=1.86 +4.86%（t=1.13，分月 3 负）→ **不能改决策规则**。

**水位分层也是死的（新做的）**：冻结行 margin 中位 **2.91%**、p10 2.31%、min 1.62%（不是「已选到最便宜的盘」）。
按 margin 五分位 ROI **不单调**：Q1(0.022) −5.52% / Q2 +8.25% / Q3 −4.37% / Q4 −2.15% / Q5(0.040) −1.93%。
margin<0.021 的 52 腿 **−19.89%（t=−1.71）** → **低水位反而更差**，因为「两边都高」通常意味着双方无信息。
→ 「继续榨水位」这条路在 pinnacle 上已经到极限，不可压缩。

**对「足球能不能赚钱」的判断**：
- 我们赢不了（已有显著证据）；但「没人能赢」我没有证据，也不相信。这两件事要分开说。
- 足球的钱在四类完全不同的东西上：执行水位 / 补贴（返水免费注）/ 交易所做市价差 / 赔率之外的信息。我这套系统做的是第五件——**用赔率解释赔率**，信息量上限就是输入的信息量。
- 竞彩返还率是产品参数不是市场结果：水位 3% 需胜率超平衡点 3pp，现在差 −4.08pp，缺口 7pp。调参补不了。

## 第十二·十三条否证：赛前异动（10-28 深夜，用户「跑掉吧」）

**先说一个自己踩的结算 bug**：押客队时 `d = s*(hs-as_) + line` 是错的（只翻了比分差
没翻让球方向），必须 `d = s*((hs-as_) + line)`。错的时候「跟 vs 反」差 +13pp 全是假的。
**自检办法：E(跟)+E(反) 应 ≈ −2m/(1+m)**（押两边各 1 单位必亏两倍水位），修完平博
−9.24% vs 理论 −7.16%，偏差来自四分线半赢半输与 598 场的抽样波动，可接受。

**最后快照时间（新实测，598 场归档）**：距开赛中位 **0.62h（37 分钟）**，56% 在 1h 内、
75.5% 在 3h 内，**10% 在开赛后（滚球报价，用「最后价」下注前必须按 `min_before_ko>0` 剔除）**。
p90 = 7.58h。生产在 T-105min 冻结是留发布窗口，与原始最后更新不冲突。

**结论：无信号。**
- 24h 窗口（平博主盘 n=752）：跟 = **+2.01%**（t=0.62）；48h（n=587）**+3.88%**（t=1.06）
- 「跟−反」的差在 48h 到 +15.37%（t=2.09），**但这是假象**：跟异动 ≈ 押降价侧 ≈ 押热门，
  差里主要是 favorite/longshot 效应，不是异动信息
- **强度分层完全不单调**（48h：0~1% 差 +19.86 / 1~2% **+43.97** / 2~4% **−6.40** /
  4~7% +19.52 / 7%+ **−6.46**）。真信号必须单调，跳动 = 噪声
- **关键对照：把两侧最后赔率都限制在 1.85~1.95**（跟/反赔率水平相当，只剩方向信息）：
  24h n=64 跟 **−9.00%**、差 −11.87%；48h n=45 跟 **−10.51%**、差 −14.73%。**方向反**
- 分月：24h 里 9 月 +8.08%（t=1.26）独占，其余 0 附近

**方法教训**：检验「方向信号」必须控制赔率水平。只要「A 侧 vs B 侧」两侧赔率不同，
差值里就混着 favorite/longshot 效应，而那个效应本身有 −6%/+5% 的量级，足以伪造显著性。

**文档已更新 `docs/backtest-design.md` §12**（未提交）：
- 否证表 9 条 → **13 条**（新增：大比分、押注侧赔率、水位分层、赛前异动）
- **命中率口径修正**：旧记的 53.0% 是 `HIT/(HIT+MISS)`，剔除了半球与走盘；正确加权
  （HALF 按 0.5）是 **49.94%**，vs 平衡点 54.02% → −4.08pp t=−2.43。**差 3pp 的口径错误
  直接把「显著」讲成了「噪声」**
- 「降水位」那条改为：**同平台挑低 `margin` 的盘无效**（最便宜 20% −5.52%），只有换渠道有效

## 第十四条否证：二串一「高盈亏比低胜率」（10-28 深夜，用户要求回测）

**数学先行（不需要样本）**：串关 ROI ≈ e1 + e2 + e1·e2，e = 单腿相对公平赔率的边缘。
单腿 e = −2.9% → 串关 **−5.7%**（水位**相加**，不是相乘）。
单腿 e = +5% → 串关 +10.25%。**串关是杠杆，不是策略**——它只放大已有 edge，不创造 edge。

**回测**：81 个交易日、598 场（legs 每场取高赔那腿）、3215 个两两组合。
命中时平均串关赔率 **3.02** → 打平需 **33.1%**，实测命中 **31.9%**，差 1.2pp = 水位的平方。
按天聚合：全部组合 **+2.84%**，95%CI [−18.5%, +24.2%]，理论 **−5.69%**。

| 规则（每天选两场） | ROI | 95%CI | 同期随机分位 |
|---|---|---|---|
| 全部组合 | +2.84% | [−18.5, +24.2] | — |
| 最高赔率两场 | **−17.02%** | [−47.5, +13.5] | **3%** |
| 最低赔率两场 | −8.02% | [−38.0, +21.9] | 17% |
| `margin` 最小两场 | +10.56% | [−21.8, +42.9] | 75% |
| **排除低水(`o≥1.88`)后最高两场** | **−30.83%** | [−67.1, +5.4] | **0%**（3000 次随机没有更差的） |

**用户的「不要低水」正好踩反**：单腿层面 1.88~2.03 曾有 +5.27%（但分月散），
串关层面它把「押冷门」的 longshot bias 平方放大。而「选最高赔率」= 押庄家认为概率最低的一侧。

**样本量硬约束**：81 天、命中率 se ≈ 5.2pp → 要证明 +1.2pp 的改善需要约 **1500 天 ≈ 4 年**。
「高手高盈亏比低胜率」不可验证的原因就在这：即使真有 +2pp 优势，也要 4 年才能统计确认。

**统计教训（重要）**：3215 个组合**不独立**（来自 81 天），se 必须**按天聚合**再算，
否则 t 被高估约 2.4 倍（裸算 ±5.0pp vs 按天 ±21.3pp）。

**没有一条腿两侧接近 1.95/1.95**。查代码 + 重放归档，分两层：

### 一、主盘判定本身没错
按 `AsianMarketConsensusAggregator` 真实逻辑（逐家去水→中位→白名单按线判定→

冻结行是**第 1 名 79.4%、前 2 名 97.7%**。`AsianFreezeSnapshotSelector.freezable()`

### 二、「主盘 = 1.94/1.94」在亚盘里数学上不可能（新实测，关键）

| 档 | imb | 水位 | 低侧赔率 |
|---|---|---|---|

| 4 | 0.2307 | 0.0659 | 1.3200 |

| Q4 | ~0.0604 | 1.8112 | 46.15% | 55.22% | −9.07pp | −9.93% | −1.79 |

**`r(imb, pick_odds) = −0.910`（R²=0.83）** → 两者是同一件事。控制赔率窄带后方向翻转：
1.83~1.87 低 imb **−3.63%** / 1.85~1.89 **+1.00%** / 1.87~1.91 +7.81%。**不是独立维度。**

按 +4.86%/sd 0.85 要 t=2 需 **n≈1225**，当前每月 po≥1.86 约 81 腿 → **还要 15 个月**。

## 反买对手盘的精确答案 + 一条可直接判定的恒等式（10-28 深夜，用户「买对手盘ROI多少」）

**恒等式（这是本节最有价值的东西，可推广到任何「翻转」策略）：**
```
E[反] = − 2m/(1+m) − E[原]
```
因为押两侧各 1 单位必亏两份水。实测自检：全部 −0.87% + (−4.23%) = **−5.11%**
vs 理论 −5.86%（差 0.75pp，来自四分线半赢半输的非线性）。
让球 −4.58% vs −5.44%；大小球 −5.65% vs −6.29%。

**⇒ 反买赚钱的判据不是「原方向为负」，而是「原方向在这一层亏损超过两倍水位（≈5.9%）」。**
全部原方向只 −0.87%，远不到门槛 → 全部反买 **−4.23%**，比原样更差 3.36pp。

**分层结果（884 腿，imb 四分位）：**
| 组 | 押注均赔 | 原 ROI | 反买均赔 | 反买 ROI | 反买 t |
|---|---|---|---|---|---|
| Q1 | 1.8854 | +9.06% | 2.0024 | **−14.83%** | −2.42 |
| Q2 | 1.8644 | +0.29% | 2.0250 | −5.77% | −0.92 |
| Q3 | 1.8431 | −2.91% | 2.0529 | −2.33% | −0.36 |
| Q4 | 1.8112 | −9.93% | 2.0894 | **+5.99%** | +0.94 |

只有 Q4（imb>3.06pp，即押注价 ≲1.81 的热门侧）跨过 5.9% 门槛。
**反买 Q4 分月：+27.14 / −3.74 / +16.91 / −6.92 / +16.12（3正2负，乱跳）**，
95%CI [−6.53,+18.52]，要 t=2 需 **n≈1004 → 22 个月**。

**组合方案（同一 884 腿样本空间）：**
| 方案 | n | ROI | t |
|---|---|---|---|
| A 原样 | 884 | −0.87% | −0.30 |
| B 全部反买 | 884 | **−4.23%** | −1.34 |
| **C Q1~Q3原样 + Q4反买** | 884 | **+3.11%** | +1.05 |
| D 跳过 Q4 | 663 | +2.15% | +0.64 |
| E 只反买 po<1.83 | 164 | +2.04% | +0.28 |
| F po<1.83反买其余原样 | 884 | +0.82% | +0.28 |

C 分月：+13.59 / +3.80 / +8.01 / −5.39 / +1.85（4 正 1 负）。但 C 的分组边界
（imb>3.06pp）是看了结果定的，属 in-sample，**+3.11% 有向上偏差**。

**用户观察「买的赔率低、胜率也低」的强度检验**（等效胜率 = (1+ROI)/均赔 vs 去水隐含 1/(po(1+m))）：
| 组 | 均赔 | 等效胜率 | 去水隐含 | 差 | t |
|---|---|---|---|---|---|
| Q1 | 1.8854 | 57.84% | 51.50% | **+6.34pp** | **+1.91** |
| Q2 | 1.8644 | 53.79% | 52.06% | +1.73pp | +0.52 |
| Q3 | 1.8431 | 52.68% | 52.69% | −0.01pp | 0.00 |
| Q4 | 1.8112 | 49.73% | 53.56% | **−3.83pp** | −1.14 |

**方向对，强度不够。** Q1 的 +6.34pp（t=1.91）比 Q4 的负向更强——即模型在**平衡场次**
才有可测优势，在一边倒场次只是「没那么差」，不是「显著押反」。
所以「反买热门」是在替一个 t=−1.14 的效应付两倍水。

**结论：不要反买。** 全部反买 −4.23%；分层反买最乐观 +5.99% 但 t=0.94、需 22 个月。
真实可用的仍是「跳过最热那一档」，且它同样只有 t=0.64。
