## 十六、竞彩「买平/让平」策略化：唯一稳定分离是官方让球线 + 必发换算

### 新增工具
`.workbuddy/tmp/draw_model.py`（双泊松单场拟合）、`draw_run.py`（598 场批量）、

数据链：`odds-payload/{ext}.json`（多档让球 4 + 大小球 5，6~7 家）+ `had.csv` + `matches.csv`
→ **580 场**有完整两边（缺 18 场亚盘不足 4 档）。

### 模型怎么算的（可复用）
双泊松解耦两阶段：**大小球多档 → 黄金分割解 μ**；**让球多档 → 给定 μ 解 λh:λa 分裂 w**
（覆盖概率单调于 w）。四分盘拆成两个半档各半权；走盘记 0.5。
P(净胜=k) 从 diff 分布直接取，**让平 = P(diff = −official_handicap)**。

### 关键校准结果（580 场）
| | Brier | 模型均值 | 实际 |
|---|---|---|---|
| 平局：模型 | 0.2001 | 0.2295 | 0.2776 |
| 平局：竞彩去水 | **0.1990** | 0.2444 | 0.2776 |
| 让平：模型 | **0.1740** | 0.2260 | 0.2241 |
| 让平：竞彩去水 | 0.1758 | 0.2449 | 0.2241 |

**两条南辕北辙的结论**：
1. **平局侧模型没有信息优势**（独立双泊松结构性低估平局，bias 0.83）。「用亚盘反解找竞彩平局错价」这条路**死了**。
2. **净胜差侧模型更准**（Brier 优 0.0018），而竞彩让平**高估 8.5%**（0.2449 vs 0.2241）
   → **买让平必亏 −15.7%，是六选项第二差**。用户点名的两个选项，让平是明确的反向。

### 主样本 hcap=−1 六选项（584 场）
买平 **−6.46%** / 买让平 **−15.68%**(t=−2.44) / 买主胜 −11.37%(t=−3.10) /
买客胜 −21.42% / 买让主 −11.78% / 买让客 −11.53%。**六项全负，买平最优但仍是负。**

### 必发换算（本轮最有用的产出）
同一批注单换渠道：`ROI_bf = Σ[p·(o_bf−1)·(1−c) − (1−p)]`，**c=2% 佣金**，`o_bf = 1/(p_jc·(1+b))`。
| 必发隐含 / 竞彩隐含 | ROI |
|---|---|
| 1.00（一样错） | **+4.04%** |
| 1.02 | +2.01% |
| 1.03 | +1.02% |
| **1.04（盈亏平衡）** | **+0.06%** |
| 1.06 | −1.82% |

**换算口径**：竞彩水位 12.92% 是 4.3 倍于必发佣金。**必发只要保留竞彩 96% 的 draw bias 就打平** ——
比「必发要完全无效」宽松得多。这是 draw bias 第一次有转正可能。

### 可执行判据（不需要模型，不需要新数据）
```
S = 1/o_主 + 1/o_平 + 1/o_客        # 竞彩三路
公平价 = o_平 × S
若 必发平局 back 价 ≥ 公平价 × 0.96  → 买
```
例：1.80 / 3.60 / 4.20 → S=1.072 → 公平价 3.859 → 门槛 **3.705**。

### 明确不要做的事（都试过了）
- **按联赛筛**：17 个联赛里 美国 +116.86%(t=2.74) / 挪威 −61.55%(t=−2.86) / 欧罗巴 −64.91%(t=−2.67)
  —— 挑 3 个显著的 = 多重比较，纯噪声
- **按平赔档筛**（hcap=−1, 7/8/9 月）：3.0-3.4 合计 +1.2%、3.4-3.8 +2.0%，但分月 −29%/+2%/+18% 乱跳
- **买「让主+让客」押非让平**：子集 −8.78%，全样本约 −11%（两腿各付一份水，抵不过让平高估的 8.5%）
- **用模型 P(平) 做信号**：模型系统性低于竞彩（−0.0149），方向反了

## 十七、「竞彩接近打平 → 搬到亚盘肯定赚」不成立（已证否）

### 致命点：亚盘没有「平局」这个标的物
- AH 0 盘：平局**走盘退本金**，不是可下注结果
- AH −1：主队赢 1 球走盘
- 「同时押主队 0 盘 + 客队 0 盘」平局两边都走盘 → 净 0，无意义
- **draw bias 只在能买平局的市场（1X2）才吃得到**，亚盘结构上不存在这个选项

### 「hcap=−1 & 主胜赔<2.0」这条规则的真相
n=462, ROI **−0.17%** 但 **se = 7.94**（不是小数！），
bootstrap 95%CI **[−15.41, +15.86]**，正概率 48%。**「点估计精确等于 0」≠「已经打平」，是「什么都测不出来」。**
平赔均 4.03（这批是 462 场里的高赔平），并不是我之前以为的「低赔平」。

### 硬搬到亚盘的实测（同一批 462 场中 253 场有多档报价）
| 标的 | n | ROI | t | 命中 |
|---|---|---|---|---|
| 客队 +1（买平唯一可表达近似） | 253 | **−3.66%** | −0.76 | 44.7% |
| 主队 −1（原让球方） | 253 | −8.87% | −1.50 | 34.0% |
| 客队 0 盘 | 253 | −20.03% | −2.68 | 15.4% |
| 主队 0 盘 | 253 | −0.40% | −0.14 | 55.3% |

**对照全 598 场无筛选：客队+1 −3.30%** → **筛选后 −3.66% 比不筛还差，信号零增益。**

### 为什么必然如此（这是本轮最干净的证据）
锐价亚盘 hcap margin 中位 **3.60%**，客队+1 实测 **−3.66%** → **ROI ≈ −水位，误差 0.06pp**。
竞彩让客 −11.53% vs 水位 12.92% → 差 +1.4pp（draw bias 残留）。
**同一个概率事件（主队不赢）在两个渠道都精确等于「负的水位」→ 该事件定价有效，没有可吃的东西。**

### 结论
想把 −0.17% 变现，唯一路径是**保留「平局」这个标的物 + 换低水位渠道**（必发 1X2 back，见第十六节换算）。
搬到亚盘 = 换了标的物，bias 立刻消失，只剩水位差。

## 十八、必发 1X2 实测：能拉、能回测，但「换渠道」这条路余量为零

### 数据可用性（已实证）
- `/nova/tf/odds?matchId=&marketId=1` 与 `/nova/tf/odds-history?matchId=&marketId=1` **都返回胜平负**
  （`Home`/`Draw`/`Away` + `points[]`），**默认不返回**——不传 `marketId` 只有 4 让球 / 5 大小球。
- 玩法字典 `/nova/tf/bet-types` 14 种，`marketId=1` = Match Winner = 胜平负。
- 7 家：必发 / 平博 / 1xBet / Bet365 / 韦德 / 威廉希尔 / 利记（+10Bet 覆盖较低）。
- **可回溯到 6 月中**（与亚盘一致，约 4 个月）；每场 1 次额度。
- **两个缺陷**：`points[]` 极稀疏（每选项 1~9 个点，不是定时采样）；约 5% 场次返 404「未找到赔率变动记录」。

**必发 7.1% 是博彩公司水位，不是 2% 佣金**。上一轮「+4.04%」的换算整体作废。

4. 若真有交易所直连（抽水 ~2.5%），换算约 +3.1%——**但本数据源给不了这个价格**，只能自己去开。

## 十九、买平「缩小范围能否盈利」——不能，而且能证明为什么

在 1026 场（652 场 hcap=−1）上按 10 个维度切了 35 片（`.workbuddy/tmp/draw_optimize.py`）：

- **没有一片 |t|>2**（最高 +40.08%、t=1.87；6 月 +70.19%、t=1.93）。
- 「去水平局概率」十分位 ROI：**−50.3 / +25.6 / +9.2 / −22.9 / −15.7 / +40.1 / +23.5 / −16.6 / +11.5 / −19.0%**
  —— 完全非单调。**偏差是常数，不随比赛类型变化**，所以切片在原理上无法提高 ROI（只能提高噪声）。
- 热门赔率四分位：−5.13 / −6.76 / +9.79 / −3.92。平赔六档：−6.21 / +6.86 / +32.90 / −16.24 / −17.98 / −4.19。
- 训练(7-8 月 365 场)/验证(9 月 219 场)：五个平赔档**四个符号翻转**（3.5-3.7 训练 +2.02% → 验证 −7.56%）。

### 为什么切片必然无效（可复用的量级判断）
- 单注 pnl sd ≈ **1.6**（赔率 3.6、命中 26%）。se(ROI) = 1.6/√n → 620 场 **±6.4pp**、65 场 **±20pp**。
- 要证明 **+5%** 需 n = (2×1.6/0.05)² ≈ **4096 场**，而竞彩历史总共只有 **1026 场**。
- 最刺眼的一个事实：**68 场（6 月 27 + 10 月 41）就能把 584 场的结论从 −6.46% 拉到 −1.51%**（对应平博 +0.8% → +6.2%）。任何「缩小范围」都比这 68 场还少。

### 结论
- **唯一真实的杠杆是水位，不是选场**。平博 3.64% 已是博彩公司地板；交易所直连（2%）换算 +1.2~2.4%，0% 才 +3.2%（用中位 uplift 1.0648 算）。而那个 7% 的 bias 本身 se 就有 6.6pp。
- 文献（Cain/Law/Peel、Deschamps & Gergaud）给 1X2 draw bias 的量级是 **2~4%**，与我们 7%±7 不矛盾——**都指向「在 3.6% 水位下净余量 ≈ 0」**。
- 跨庄分歧检验（竞彩 vs 平博 去水差三分位，n=78）：−37.6 / −31.0 / −17.9%，方向与「平博低估→买」相反且样本无功效。**不值得追加额度。**

## 二十、数学期望 + 「亚盘初盘/变化 + 竞彩」预测平局：已证否（有干净证明）

### 一、各渠道买平的数学期望（584 场主样本 ROI −6.46% 为基准）
`EV = (1+提升) × (1+ROI_竞彩) − 1`

| 渠道 | 实测提升 | EV | 验证到 t=2 需注数 |
|---|---|---|---|
| 竞彩 | — | −6.46% | — |
| 必发/ Bet365 | +4.5% | **−2.3%** | — |
| 1xBet | +7.11% | +0.19% | 284 万 |
| **平博** | **+7.91%** | **+0.94%** | **11.6 万** |

**EV 区间 [−7.65%, +9.04%]**（uplift CI 贡献 ±1.4pp，ROI_竞彩 的 se 6.61pp 贡献 ±7pp）。
一年 1500 注（每天 5 注）：期望 +14 单位、标准差 62 单位 → **即使 +0.94% 是真的，一年后亏损概率 41%**。
bias 敏感表（ROI = bias/(1+margin) − 1）：bias 1.00 时连平博都 −3.5%；1.04 → 平博 +0.35%；1.0711（点估）→ +3.35%（理论）；1.09 → +5.17%。

### 二、亚盘初盘/变化能否提升平局预测 —— 不能，四条独立证据
工具：`ah_draw_join.py`（527 场，平博多档反解双泊松，两个时点：OPEN=各档最早、FREEZE=T−105min）、
`ah_draw_test.py` / `ah_draw_test2.py`。**零额度消耗**（全用 `odds-payload` + `had.csv`）。

**1. 它们是同一个变量**：`corr(p_亚盘反解, p_竞彩去水) = 0.9585`（logit 空间 0.9602）。

**2. 嵌套 logistic + 似然比检验**：仅竞彩 2ll=−596.54 → 加亚盘反解 −595.08，**LR=1.46（df=1，临界 3.84）→ 不显著**。
（单看 z=+4.60 是共线性假象，同时 logit(p_jc) 系数翻成 −0.41，正常。）

**3. 5 折交叉验证 Brier（决定性）**：
| 模型 | 样本外 Brier | 相对 |
|---|---|---|
| A 仅竞彩 | 0.19123 | — |
| B 竞彩+亚盘反解(冻结) | 0.19108 | −0.00015（等于没有） |
| C 竞彩+亚盘初盘 | 0.19133 | +0.00010 |
| **D 竞彩+移动+Δ线** | **0.19230** | **+0.00108（更差）** |
| E 全上 | 0.19228 | +0.00106 |
→ **加入初盘与变化后，样本外预测变差，不是变好。**

**4. 残差不是信息，是「长赔平局」的换名**：`corr(平赔, p_f−p_jc) = +0.687`。
残差四分位实际平局率 26.0 / 34.4 / 27.5 / **17.2%**（Q4 最看高平局却最少平）。
直接押「模型比竞彩更看高平局」：n=276 **ROI −8.86%**（比不筛的 −6.46% 更差），阈值提到 +1pp 是 −25.81%。

**5. 移动单独也没有**：`corr(移动, 实际平局) = +0.0688`；控制平赔后三分位乱跳（低平赔档 22.7→43.2→31.1%）。
**68% 场次主盘线整场不动**（Δ线 −0.25/0/+0.25 = 15.2%/68.1%/15.6%），且三组 t 分别 −1.08/−0.39/−0.03。

### 结论
**亚盘和竞彩不是两个信息源，是同一份信息的两种报价。** 亚盘反解出来的 P(平) 精度已等于市场
（Brier 0.1911 vs 竞彩 0.1905），说明抽取器没问题——问题是里面没有竞彩没有的东西。
唯一独立于市场的 λ 来源仍是 NovaAPI 的 `feature/result`（滚动 20 场），不是盘口。
